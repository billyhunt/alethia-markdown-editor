# Security policy

If you believe you have found a security vulnerability in Alethia, please do
not disclose it in a public issue. Use this repository's private vulnerability
reporting channel, if it is enabled, or contact the maintainer privately before
publishing details.

Useful reports explain the affected version, the required conditions, a
reproducible proof of concept, and the potential impact. Alethia's most
sensitive boundary is file access: reports involving path validation, renderer
privileges, IPC, external navigation, or document writes are especially useful.
